Consulta Capítulo 12

Consulta rápida

Os comandos da oficina organizados por tarefa. Busque pelo que você quer fazer (“desfazer”, “branch”) ou pelo comando.

Configurar

git config --global user.name "Nome"Define seu nome nos commits
git config --global user.email "email"Define seu e-mail nos commits
git config --global init.defaultBranch mainProjetos novos começam na branch main
git config --global core.editor "code --wait"Usa o VS Code como editor do Git
git config --global --listMostra todas as configurações
git config --global alias.lg "log --oneline --graph --all"Cria um atalho (alias) para um comando

Começar um projeto

git initTransforma a pasta atual em repositório
git clone URLBaixa um repositório existente (copiar, download)
git remote add origin URLConecta o repositório local a um remoto
git remote -vMostra os remotos configurados
git remote set-url origin URLTroca o endereço do remoto

Salvar versões

git statusMostra o que mudou e o que está preparado
git add arquivoPrepara um arquivo para o commit (stage)
git add .Prepara tudo o que mudou
git add -pEscolhe trecho por trecho o que preparar
git commit -m "mensagem"Registra um commit (salvar versão)
git commit -am "mensagem"Adiciona arquivos rastreados e faz commit

Ver histórico e diferenças

git log --onelineHistórico resumido
git log --oneline --graph --allHistórico em forma de grafo, todas as branches
git show HASHDetalhes e diff de um commit
git diffMudanças ainda não preparadas
git diff --stagedMudanças preparadas para o commit
git diff main..featureDiferença entre duas branches (comparar)
git blame arquivoQuem alterou cada linha e quando

Branches

git branchLista branches locais (listar)
git branch -aLista também as do remoto
git switch -c nomeCria uma branch e entra nela (criar)
git switch nomeTroca de branch (mudar, trocar)
git switch -Volta para a branch anterior
git branch -m novo-nomeRenomeia a branch atual (renomear)
git branch -d nomeApaga branch já integrada (deletar, apagar)
git push origin --delete nomeApaga a branch no GitHub

Juntar trabalhos

git merge nomeTraz a branch nome para a branch atual (juntar, integrar)
git merge --no-ff nomeMerge sempre com commit de merge
git merge --abortCancela um merge com conflito
git rebase mainReaplica seus commits depois da main
git rebase --continueSegue o rebase após resolver conflito
git rebase --abortCancela o rebase
git cherry-pick HASHCopia um commit específico para cá

Trabalhar com o remoto

git push -u origin nomePrimeiro envio de uma branch (enviar, publicar, upload)
git pushEnvia commits (enviar, subir)
git fetchBaixa novidades sem mexer na sua branch
git pullBaixa e junta na branch atual (atualizar, receber)
git pull --rebaseAtualiza reaplicando seus commits por cima
git branch -vvMostra a ligação com o remoto e se está à frente/atrás
git push --force-with-leaseForça o envio com segurança (só na sua branch)

Desfazer

git restore arquivoDescarta mudanças no arquivo (voltar, desfazer)
git restore --staged arquivoTira o arquivo do stage
git commit --amendCorrige o último commit (antes do push)
git reset --soft HEAD~1Desfaz o último commit, mantém as mudanças
git reset --hard HEAD~1Desfaz o último commit e descarta as mudanças
git revert HASHCria commit que desfaz outro (seguro após push)
git reflogHistórico de onde o HEAD esteve (recuperar commits perdidos)
git clean -fdApaga arquivos não rastreados (cuidado)

Guardar temporariamente

git stashGuarda as mudanças e limpa a pasta (gaveta)
git stash -uGuarda também arquivos novos
git stash listLista o que está guardado
git stash popDevolve as últimas mudanças guardadas

Tags e versões

git tag v1.0Marca o commit atual como versão
git tag -a v1.0 -m "primeira versão"Tag com descrição
git push --tagsEnvia as tags para o GitHub

Glossário

Repositório (repo)
Pasta com histórico Git. O histórico fica na subpasta oculta .git.
Commit
Uma versão salva do projeto, com autor, data, mensagem e ponteiro para o commit anterior.
Hash
Identificador único de um commit, como 3f9a2c1.
Staging / index
Área onde você prepara o que vai entrar no próximo commit.
Branch
Etiqueta móvel que aponta para um commit e representa uma linha de trabalho.
HEAD
Indica em qual branch (ou commit) você está agora.
main / master
Nome usual da branch principal. master é o nome antigo.
Merge
Juntar o histórico de uma branch em outra.
Fast-forward
Merge em que a branch só avança, sem commit de merge.
Rebase
Reaplicar commits sobre outra base, criando cópias novas.
Conflito
Quando duas mudanças nas mesmas linhas precisam de decisão humana.
Remoto (origin)
Outra cópia do repositório, normalmente no GitHub. origin é o nome padrão.
origin/main
Última posição conhecida da branch main no remoto.
Upstream
A branch remota ligada à sua branch local. Também é o nome comum do repositório original num fork.
Clone
Cópia completa de um repositório remoto para o seu computador.
Fork
Cópia de um repositório para a sua conta no GitHub.
Push / Pull / Fetch
Enviar commits / baixar e juntar / só baixar.
Pull request (PR)
Pedido para juntar uma branch em outra, com revisão. No GitLab: merge request.
Issue
Tarefa, bug ou ideia registrada no GitHub.
Tag
Etiqueta fixa para marcar uma versão (v1.0). Diferente da branch, não se move.
Stash
Gaveta temporária para mudanças sem commit.
Detached HEAD
Quando o HEAD aponta direto para um commit, sem branch.
.gitignore
Arquivo com a lista do que o Git deve ignorar.
