Prática Capítulo 11

Laboratório interativo

Um terminal de mentira com um grafo de verdade. Digite comandos Git e veja o histórico mudar na hora. Nada aqui afeta o seu computador, então erre à vontade.

Terminal

Digite help para ver os comandos. Use ↑ para repetir comandos e reset para recomeçar. Para simular um colega enviando algo ao GitHub, use colega commit -m "...".

Desafios

Clique em Carregar para preparar o repositório de cada desafio. Quando o objetivo for cumprido, ele é marcado como concluído (fica salvo neste navegador).

    Prática real em dupla

    Agora com o GitHub de verdade. Façam em dupla, cada pessoa no seu computador. Vamos chamar de Pessoa A e Pessoa B.

    1. A cria o repositório

      No GitHub: New repository → nome pratica-git → marque Add a README → Create. Depois, em Settings → Collaborators, convide a Pessoa B.

    2. B aceita o convite e as duas pessoas clonam 
      git clone https://github.com/PESSOA-A/pratica-git.git
cd pratica-git
    3. Cada pessoa cria a sua branch e um arquivo 
      git switch -c feature/ana
echo "Oi, eu sou a Ana" > ana.txt
git add ana.txt
git commit -m "adiciona apresentação da Ana"
git push -u origin feature/ana
    4. Pull request cruzado

      Cada pessoa abre um PR da sua branch para a main e pede revisão da outra. Revise, deixe um comentário, aprove e faça o merge.

    5. Atualizem a main 
      git switch main
git pull
ls   # os dois arquivos devem aparecer
    6. Agora, um conflito de propósito

      As duas pessoas criam uma branch nova e editam a mesma linha do README.md com textos diferentes. Commit, push e PR. O primeiro PR entra sem problema; o segundo vai acusar conflito.

    7. Resolva o conflito 
      git switch main
git pull
git switch minha-branch
git merge main
# resolva o README.md no VS Code, depois:
git add README.md
git commit
git push

      O PR se atualiza e pode ser integrado. Parabéns: esse é o ciclo completo de colaboração.
