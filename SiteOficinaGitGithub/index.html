Antes de abrir o terminal

Ferramenta O que faz Onde funciona
Git Registra versões, compara alterações e une linhas de trabalho. No seu computador; commits não exigem internet.
GitHub Hospeda repositórios Git e organiza colaboração, revisões e tarefas. Na web e por integrações.
GitHub Desktop Oferece uma interface gráfica para operações do Git. Aplicativo no computador.

Uma trilha, do básico à colaboração

Leia em sequência ou abra diretamente o assunto de que precisa.

01 / CAPÍTULO↗

Instalação e primeiros passos

Prepare o ambiente e entenda o que está sendo salvo antes de enviar qualquer arquivo.

02 / CAPÍTULO↗

Repositórios, clone e fork

Escolha entre começar um projeto, baixar uma cópia de trabalho ou contribuir em um projeto de outra pessoa.

03 / CAPÍTULO↗

Commits e sincronização

Registre mudanças com intenção, confira o que está enviando e mantenha o trabalho atualizado.

04 / CAPÍTULO↗

Branches: trabalho em paralelo

A branch dá um nome a uma linha de desenvolvimento. Você pode experimentar sem alterar imediatamente a versão principal.

05 / CAPÍTULO↗

Merge, pull requests e conflitos

Una mudanças com revisão. Entenda o destino do merge e resolva conflitos preservando o comportamento esperado.

06 / CAPÍTULO↗

GitHub Desktop

Faça o mesmo fluxo de versionamento usando uma interface visual. Os conceitos de branch, commit e merge continuam iguais.

07 / CAPÍTULO↗

Markdown: documentação que se lê

Arquivos .md usam texto simples com marcações. No GitHub, eles viram documentação formatada, descrições de issues e pull requests.

08 / CAPÍTULO↗

GitHub: organize e publique

Use o repositório como ponto de encontro do projeto: código, tarefas, revisão, documentação e publicação.

09 / CAPÍTULO↗

Consulta rápida e prática

Encontre um comando, entenda mensagens frequentes e conclua um exercício completo de colaboração.

O fluxo que você vai praticar

  1. Prepare: instale o Git, configure a autoria e clone ou crie um repositório.
  2. Trabalhe: crie uma branch, edite arquivos e registre commits pequenos.
  3. Compartilhe: envie a branch, abra um pull request e receba revisão.
  4. Integre: resolva conflitos, faça o merge e atualize sua cópia local.
Como usar os exemplos: substitua SEU-USUARIO, SEU-EMAIL e nomes de repositórios. Execute os comandos dentro da pasta correta. Os blocos não incluem o símbolo $, para facilitar a cópia.
