GitHub Desktop

Faça o mesmo fluxo de versionamento usando uma interface visual. Os conceitos de branch, commit e merge continuam iguais.

Configure e abra um repositório

  1. Instale o GitHub Desktop e entre na sua conta pelo navegador.
  2. Confira o nome e o e-mail usados nos commits em Options/Preferences → Git, conforme o sistema.
  3. Use File → Clone repository para clonar do GitHub ou pela URL. Escolha a pasta de destino.
  4. Para um repositório Git já existente no computador, use File → Add local repository. Para criar um novo, use File → New repository.

Conheça a interface

Current branchConferir a branch atual, trocar de branch ou criar outra.

Push origin / Publish branchEnviar commits ou publicar uma branch que ainda só existe localmente.

Do arquivo alterado ao pull request

  1. Com a main selecionada, clique em Fetch origin e, se necessário, Pull origin.
  2. Abra Current branch → New branch e crie feature/menu a partir de main.
  3. Abra o projeto no seu editor, altere os arquivos e salve.
  4. Volte ao Desktop. Em Changes, leia as diferenças e marque só o que deseja incluir.
  5. Escreva um Summary claro. Clique em Commit to feature/menu.
  6. Clique em Publish branch no primeiro envio ou em Push origin nos seguintes.
  7. Use a ação de criar/visualizar pull request para abrir o GitHub. Confira o destino e solicite revisão.
Commit ainda é local. Se você fechar o aplicativo antes do push, os commits continuam no seu computador, mas seus colegas ainda não os recebem.

Merge e conflitos na interface

Para integrar localmente, selecione primeiro a branch de destino. No menu Branch → Merge into current branch, escolha a origem. Se houver conflito, abra os arquivos no editor, resolva o conteúdo e siga a orientação do Desktop para concluir o merge.

Se a equipe trabalha com PRs e proteção da main, conclua a revisão e o merge no GitHub. Depois selecione main no Desktop e faça Fetch/Pull.

Você pode alternar entre Desktop e terminal no mesmo repositório. Evite executar operações simultâneas e confira a branch antes de editar.
