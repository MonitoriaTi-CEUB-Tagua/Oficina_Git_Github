01 / Instale as ferramentas

ESSENCIAL PARA O TERMINAL

Git

Escolha o instalador do seu sistema. No Windows, o pacote inclui o Git Bash.

Baixar Git ↗
ALTERNATIVA VISUAL

GitHub Desktop

Cliente oficial para Windows e macOS. No Linux, use Git no terminal ou outro cliente compatível.

Baixar Desktop ↗

Crie também sua conta em github.com/signup. Um editor como o Visual Studio Code é opcional.

terminal
git --version

Os exemplos de terminal podem ser seguidos no Git Bash do Windows ou no terminal de macOS/Linux. No PowerShell, os comandos Git são iguais; comandos de criação de arquivos podem ter diferenças.

Se o comando não for encontrado, reabra o terminal após instalar e confira se o Git foi adicionado ao PATH.

02 / Configure a autoria

terminal
git config --global user.name "Seu Nome"
git config --global user.email "SEU-EMAIL"
git config --global init.defaultBranch main
git config --global --list

Nome e e-mail identificam o autor dos commits. Use um e-mail associado à sua conta ou o endereço noreply fornecido em GitHub → Settings → Emails. --global aplica a configuração ao seu usuário; sem ele, vale apenas para o repositório atual.

Autoria não é login. Configurar nome e e-mail não autentica sua conta no GitHub.

03 / Conecte-se ao GitHub

Para um repositório público, normalmente você pode clonar sem login. Para enviar alterações, precisa de autenticação e permissão.

Caminho Como funciona
Desktop Entre pelo navegador quando o aplicativo solicitar. É o caminho mais simples para iniciar.
HTTPS Com Git Credential Manager configurado, siga o login pelo navegador. Se houver solicitação de senha no terminal, use um token adequado; a senha da conta não autentica operações Git por HTTPS.
SSH Cadastre sua chave pública no GitHub e use uma URL como git@github.com:usuario/projeto.git. Mantenha a chave privada no seu computador.

Veja o guia oficial de SSH. Nunca cole tokens em comandos, URLs ou arquivos versionados.

04 / Entenda as três áreas

Área Significado Comando para inspecionar
Diretório de trabalho Arquivos que você está editando. git diff
Stage / index Alterações selecionadas para o próximo commit. git diff --staged
Histórico Commits já registrados, com identificador e autoria. git log --oneline
Salvar ≠ commit ≠ push. Salvar grava o arquivo. Commit registra uma versão local. Push envia commits ao repositório remoto.
