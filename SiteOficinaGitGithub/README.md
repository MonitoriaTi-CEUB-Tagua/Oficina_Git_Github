# Oficina de GitHub da Monitoria

Este repositório reúne o material de apoio da oficina de GitHub da monitoria. Ele será publicado no GitHub Pages e terá uma página HTML para apresentar o conteúdo da oficina, além deste README para orientar a monitoria e explicar a organização do projeto.

O material pode ser atualizado conforme as oficinas avancem. A ideia é manter aqui o conteúdo principal e, futuramente, pode ser adicionada uma pasta específica para commits, exercícios e exemplos práticos. Também poderá ser criado um repositório separado para treino, com atividades e projetos para os participantes praticarem.
